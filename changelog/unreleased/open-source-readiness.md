Voxen's public documentation now matches the integrated agent architecture,
the README presents the chat and knowledge-library experience, and production
dependencies were updated to patched releases. Repository policy is also
versioned for read-only workflow defaults and a clean squash-only history. The
public covers use anonymous demo data, and Dependabot monitors every supported
container image.

<!-- pt-BR -->

A documentação pública da Voxen agora corresponde à arquitetura com agente
integrado, o README apresenta as experiências de chat e biblioteca de
conhecimento, e dependências de produção foram atualizadas para versões
corrigidas. A política do repositório também passa a ser versionada com
permissões de workflow somente leitura por padrão e histórico limpo por squash.
As capas públicas usam dados demonstrativos anônimos, e o Dependabot monitora
todas as imagens de container suportadas.
