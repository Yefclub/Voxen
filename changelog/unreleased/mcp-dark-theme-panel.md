titulo_en: MCP client configuration now follows the active theme
titulo_pt_br: Configuração de clientes MCP agora acompanha o tema ativo

The client configuration panel on **Account → MCP Access** now uses the application surface palette. The panel remains readable in dark, light, and alternate interface themes instead of rendering a light text color as its background.

<!-- pt-BR -->

O painel de configuração de clientes em **Conta → Acesso MCP** agora usa a paleta de superfícies da aplicação. O painel permanece legível nos temas escuro, claro e nas interfaces alternativas, sem aplicar uma cor clara de texto como fundo.
