---
tipo: feat
titulo_en: A newer published release is visible in navigation
titulo_pt_br: Uma nova release publicada aparece na navegação
---

Voxen now checks the official GitHub stable release from the server and shows
an update notice directly above What's new only when that release is newer than
the running build. The notice identifies the installed version and whether the
instance is running a development or production build. GitHub failures remain
silent and never interrupt navigation.

<!-- pt-BR -->

A Voxen agora consulta no servidor a release estável oficial do GitHub e mostra
um aviso de atualização logo acima de Novidades somente quando ela é posterior
ao build em execução. O aviso identifica a versão instalada e se a instância
está em desenvolvimento ou produção. Falhas do GitHub permanecem silenciosas e
nunca interrompem a navegação.
