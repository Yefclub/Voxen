A new **AI providers** page under your account lets you add API keys for OpenAI, Anthropic, OpenRouter and xAI. Each key is checked with the provider when you save it, stored encrypted on your server, and never shown again — only its last four characters appear. You then pick a model for each role (fast, standard, vision and speech-to-text) from a curated list with estimated prices; saving your first valid key fills these roles automatically. Anthropic has no speech-to-text, so transcription needs OpenAI, xAI or OpenRouter. These keys will power link capture in an upcoming release; the knowledge base keeps working without any of them.

<!-- pt-BR -->

A nova página **Provedores de IA**, na sua conta, permite adicionar chaves de API da OpenAI, Anthropic, OpenRouter e xAI. Cada chave é verificada com o provedor ao salvar, fica cifrada no seu servidor e nunca é exibida de novo — só os quatro últimos caracteres aparecem. Depois você escolhe o modelo de cada papel (rápido, padrão, visão e transcrição) numa lista curada com preços estimados; a primeira chave válida já preenche esses papéis. A Anthropic não oferece transcrição, então ela exige OpenAI, xAI ou OpenRouter. Essas chaves vão alimentar a captura de links numa próxima versão; a base de conhecimento continua funcionando sem nenhuma delas.
