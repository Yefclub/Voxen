tipo: fix
titulo_en: Legacy package retirement now has one deletion policy
titulo_pt_br: Descontinuação de packages legados agora tem uma única política de exclusão
---

The public release contract now consistently requires deleting the obsolete
web, worker, and chat packages together with all historical versions. The
release history and automated readiness checks enforce the same policy.

<!-- pt-BR -->

O contrato público de release agora exige de forma consistente a exclusão dos
packages obsoletos de web, worker e chat junto com todas as versões históricas.
O histórico de releases e os checks automatizados de prontidão aplicam a mesma
política.
