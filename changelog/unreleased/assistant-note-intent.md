titulo_en: Recognize direct requests to create notes
titulo_pt_br: Reconhecimento de pedidos diretos para criar notas
---

Chat better recognizes explicit requests to create a note when its title and
text are included. Ambiguous requests still show the exact addition for
confirmation; questions, negations and quoted instructions do not authorize
library changes.

<!-- pt-BR -->

O chat reconhece melhor pedidos explícitos para criar uma nota com título e
texto. Pedidos ambíguos continuam mostrando a adição exata para confirmação;
perguntas, negações e instruções citadas não autorizam alterações na biblioteca.
