titulo_pt_br: Retira imagens legadas de componentes das releases públicas
---

Stable releases now publish the combined Voxen image as the only public
application image. Legacy web, worker, and chat component images are retained
privately for history and are no longer republished.

<!-- pt-BR -->

Releases estáveis agora publicam a imagem combinada do Voxen como a única imagem
pública da aplicação. As imagens legadas de web, worker e chat são preservadas
privadamente para histórico e não voltam a ser publicadas.
