Document the recommended Easypanel topology: one combined Voxen App image,
persistent PostgreSQL, Redis, and S3-compatible storage services, plus the
optional residential proxy agent only when a VPS needs it for media extraction.

<!-- pt-BR -->

Documenta a topologia recomendada no Easypanel: uma imagem combinada do App
Voxen, serviços persistentes de PostgreSQL, Redis e armazenamento compatível
com S3, além do agente de proxy residencial opcional somente quando uma VPS
precisar dele para extração de mídia.
