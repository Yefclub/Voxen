titulo_en: Repository topic policy converges reliably
titulo_pt_br: Política de tópicos do repositório converge corretamente
---

The repository policy checker now compares GitHub topics as a set, preventing
false drift reports when the API returns the same topics in insertion order.

<!-- pt-BR -->

O verificador de políticas do repositório agora compara os tópicos do GitHub
como um conjunto, evitando falsos desvios quando a API retorna os mesmos
tópicos na ordem de inserção.
