# Support

Voxen is an open-source project maintained on a best-effort basis. There is no
commercial service-level agreement.

## Where to ask for help

- Reproducible bug: open an issue using the bug-report form.
- Feature request: open an issue using the feature-request form.
- Usage or deployment question: use GitHub Discussions or the question form.
- Vulnerability: follow [SECURITY.md](SECURITY.md); do not open a public issue.

Before opening a request, review the [README](README.md),
[deployment guide](docs/en/DEPLOY.md), [development guide](docs/en/DEVELOPMENT.md),
and existing open and closed issues.

Always include the version or commit, deployment environment, relevant logs
without secrets, and clear reproduction steps.

## Outside project support

The project cannot provide general Linux, Docker, or nginx administration;
recover data without a backup; recover lost secrets such as `MASTER_KEY`; or
bypass third-party platform restrictions outside the documented behavior.
