# Suporte

O Voxen e um projeto open source mantido em melhor esforco. Nao ha SLA comercial.

## Onde pedir ajuda

- Bug reproduzivel: abra uma issue usando o template de bug.
- Pedido de feature: abra uma issue usando o template de feature.
- Duvida de uso/deploy: use GitHub Discussions ou o template de pergunta.
- Vulnerabilidade: siga [SECURITY.md](SECURITY.md), sem issue publica.

## Antes de abrir uma issue

Verifique:

- [README.md](README.md)
- [docs/DEPLOY.md](docs/DEPLOY.md)
- [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)
- Issues abertas e fechadas.

Inclua sempre:

- Versao/tag ou commit.
- Ambiente: Proxmox, VPS, Docker local, Easypanel etc.
- Logs relevantes sem secrets.
- Passos claros para reproduzir.

## O que nao e suporte do projeto

- Administracao geral de Linux/Docker/nginx fora do escopo do Voxen.
- Recuperacao de dados sem backup.
- Problemas causados por secrets perdidos, especialmente `MASTER_KEY`.
- Bypass de bloqueios de plataformas terceiras fora do uso documentado.
