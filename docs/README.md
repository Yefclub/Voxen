# Voxen documentation

The repository and contributor workflow are English-first. Technical
documentation currently has two tracks:

- **English** is the default track for GitHub readers and new changes.
- **Português (Brasil)** remains available for the existing community and must
  be updated when a change affects translated operational guidance.
