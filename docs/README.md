# Documentação — Voxen

Este diretório mantém a documentação técnica do Voxen em duas trilhas:

- **Português (Brasil)**: documentação canônica do projeto.
- **English**: documentação espelhada para usuários e contribuidores open source.

Quando uma mudança alterar arquitetura, operação, segurança, stack ou formato de dados, atualize a versão PT-BR e a versão EN no mesmo PR.
